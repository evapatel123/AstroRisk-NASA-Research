# Contributing to AstroRisk

## AstroRisk

**Author & Developer: Eva J. Patel**

Thank you for your interest in contributing to AstroRisk.

AstroRisk welcomes contributions while maintaining clear authorship,
project ownership, attribution, and research integrity.

---

# 1. Primary Author & Developer

AstroRisk was created and is primarily developed by:

**Eva J. Patel**

All contributors must preserve this attribution.

Contributions do not replace, remove, or supersede Eva J. Patel as the
author and developer of AstroRisk.

---

# 2. Contributions Are Welcome

Contributions may include:

- bug fixes
- performance improvements
- documentation
- testing
- accessibility improvements
- frontend improvements
- backend improvements
- data-analysis improvements
- visualization improvements
- research methodology suggestions
- reproducibility improvements
- security improvements

---

# 3. Attribution Requirement

Any contribution must preserve the following project attribution:

> AstroRisk — developed by Eva J. Patel

Do not remove the attribution from:

- README files
- application interfaces
- documentation
- source headers
- research materials
- project descriptions

when the attribution is already present.

---

# 4. Contributor Attribution

Contributors may be credited for their individual contributions.

For example:

```text
AstroRisk

Author & Developer:
Eva J. Patel

Contributors:
Jane Doe — visualization improvements
John Doe — testing improvements

```
